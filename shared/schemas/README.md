# ForgeSec JSON contracts

These JSON Schema 2020-12 documents define the messages exchanged by the dashboard, FastAPI server, and Windows agent.

Rules:

- `schema_version` is required in every top-level message.
- Unknown top-level properties are rejected unless a schema explicitly permits them.
- IDs and timestamps are generated by the component that creates the resource.
- Scan target lists contain at most 4,096 selected device records.
- Breaking changes require a new schema version and migration plan.

Run `python validate_schemas.py` from this directory to perform the repository-level contract checks.
